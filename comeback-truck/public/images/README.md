# The Comeback Truck — Image Assets

Drop the following image files into this directory to replace placeholders across the site.

## Required Images

- `truck-hero.jpg` — the food truck itself, ideally a clean exterior shot
- `brigman-portrait.jpg` — portrait of Brigman German
- `brigman-truck.jpg` — Brigman with the truck

## Food Photography

- `food-ribs.jpg` — BBQ ribs plate
- `food-fries.jpg` — chili cheese fries / loaded fries
- `food-fish.jpg` — fried fish basket
- `food-pulled-pork.jpg` — pulled pork sandwich
- `food-chili-dog.jpg` — chili cheese dog
- `food-meatloaf.jpg` — stuffed meatloaf

## Notes

- Recommended format: JPG, sRGB color profile
- Recommended dimensions: 1600×1200 or larger for hero/feature shots; 1200×1200 for square food shots
- Keep file sizes under 500 KB (use Sharp / Squoosh / TinyJPG)
